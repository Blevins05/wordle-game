# Wordle Game

Classic Wordle game built with Vanilla JavaScript.

## Features
- Random word selection from a curated word list
- Real word validation via Dictionary API
- Color feedback: green (correct), yellow (wrong position), grey (not in word)
- Animated reveals and keyboard support
- Win/lose modal with the solution

## Stack
HTML · CSS · Vanilla JavaScript

## How to play
1. Guess the 5-letter word in 6 attempts
2. Each guess must be a valid English word
3. Colors indicate how close your guess is
